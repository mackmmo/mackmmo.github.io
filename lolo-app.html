Lolo Climbing App

A geospatial mobile application for exploring climbing routes near Lolo Pass.

View Project

Project Overview

The Lolo Climbing App is a custom-built geospatial application designed to help climbers discover routes, filter by characteristics, and explore crags in an intuitive way.

Key Features

  • Route filtering by grade, sun exposure, and area
  • Custom spatial database using PostGIS
  • Interactive map-based exploration

Tech Stack

PostgreSQL + PostGIS
Django
JavaScript
Leaflet / Mapping
HTML & CSS

My Role

I designed and implemented the spatial database architecture, including route hierarchies, optimized filtering workflows, and built backend endpoints to serve geospatial data efficiently. Additionally, I played the role of project manager in a team of three. As project manager, I was responsible for delegating tasks to develop the frontend and UX/UI.

The Vision

As a rock climber myself and author of A Rockclimber's Guide to Lolo Pass, I wanted to create a mobile application to be used at home and out climbing to both explore Lolo climbing spatially and accurately guide the user to walls and specific routes. As with other climbing guidebook mapping applications. The UI is centered around a map used to pan and zoom to different locations, while also allowing filterable searches that output lists of routes. This filtering is made possible with a PostgreSQL/ postGIS database. The database is setup with four relational tables.
